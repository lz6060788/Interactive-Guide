# 主题类型参考

## 1. 选择原则

- `topicType` 用于帮助系统选择更合适的页面表达模板。
- 优先按内容任务选择，不要按美术风格选择。
- 不确定时，选更通用、更偏内容表达的类型。

## 2. 推荐类型

### `news-report`

适合：

- 新闻播报
- 事件更新
- 时事梳理

常见内容：

- 时间、地点、人物、事件进展、影响范围、关键数据

常见表达：

- 时间线
- 事件卡
- 地图或数据区

### `common-knowledge`

适合：

- 常识介绍
- 学科概念说明
- 课程导览
- 基础机制解释

常见内容：

- 定义
- 分类
- 原理
- 关系
- 例子

常见表达：

- 模块化讲解页
- 对比图
- 关系图
- 坐标示意

### `content-analysis`

适合：

- 内容解读
- 观点拆解
- 争议分析
- 风险与影响研判

常见内容：

- 观点
- 依据
- 逻辑链
- 风险点
- 结论

常见表达：

- 证据链
- 因果图
- 观点与依据对照区

### `scene-cover`

适合：

- 封面页
- 场景导览页
- 主题海报页

常见内容：

- 总主题
- 核心意象
- 风格氛围

常见表达：

- 单一强主体
- 强氛围背景
- 少量辅助标签

## 3. 选择示例

### 宏观经济学总览

- 推荐：`common-knowledge`
- 原因：重点是梳理三大维度和知识结构，不是做一张纯海报。

### 某条突发新闻解析

- 推荐：`news-report`
- 原因：重点是时间、事件、影响和事实组织。

### 一篇观点文章拆解

- 推荐：`content-analysis`
- 原因：重点是观点、证据和逻辑关系。

### 导览包首页封面

- 推荐：`scene-cover`
- 原因：重点是建立视觉主题和第一印象。

## 4. 实操建议

- 根节点不一定都是 `scene-cover`，知识型导览的根节点通常更适合 `common-knowledge`。
- 同一个导览包可以混用不同 `topicType`。
- 不要因为风格统一，就让所有节点都使用同一个 `topicType`。
