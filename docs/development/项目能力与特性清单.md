# 项目能力与特性清单

## 文档说明

- 目的: 盘点当前项目中所有可感知的功能与技术特性，供后续逐项判断保留、下线或重构。
- 范围: 包含管理端、服务端、通用运行时、全景运行时、基础设施与遗留候选项。
- 使用方式: 在 `处理结论` 列中填写 `保留`、`待确认`、`移除`、`合并` 等标记。
- 说明: 本文档只做能力列举，不代表当前去留判断，也暂不处理命名统一问题。

## 处理标记建议

| 标记 | 含义 |
| --- | --- |
| 保留 | 当前确认继续保留 |
| 待确认 | 还需要进一步评估 |
| 移除 | 明确不再需要 |
| 合并 | 与其他能力合并保留 |
