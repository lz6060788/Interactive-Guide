# 端到端验证流程（From Scratch）

> 适用版本：双产品架构（Atlas + Catalog），Phase 0–8 重构完成后
> 适用场景：从零开始验收整条数据流，确认重构未引入回归
> 范围：静态质量门禁 → 服务端 API → 双产物编译 → 静态自包含发布 → 浏览器 E2E

---

```bash
node --version          # 必须 >= 22

`.env` 文件只需保留以下两项；AI 相关键值可保留但已被新主干忽略：

```

## 3. 项目生命周期 API E2E

按下面顺序在另一个终端跑。

### 3.1 创建项目

```bash
curl -X POST http://localhost:8788/api/projects \
  -H 'content-type: application/json' \
  -d '{"id":"rocket","title":"商业航天样例"}'
```

记录返回的 `metadata.revision`（如 `1`）。下面所有 PATCH 都用 `x-expected-revision` 头携带它，**不传或传错就 409**。

### 3.2 上传全景图

```bash
curl -X POST "http://localhost:8788/api/projects/rocket/assets/image?id=asset-pano&expectedRevision=1" \
  -H 'content-type: image/jpeg' \
  --data-binary @./fixtures/pano.jpg
```

返回 `data.metadata.revision` 自增为 `2`。

### 3.3 绑定全景图 + 写入三段产业链知识

```bash
# 绑定 panorama.assetId
curl -X PUT http://localhost:8788/api/projects/rocket/panorama \
  -H 'content-type: application/json' \
  -H "x-expected-revision: 2" \
  -d '{"assetId":"asset-pano","categories":{},"items":{}}'

# 写入知识：3 stage × N category × M item
curl -X PUT http://localhost:8788/api/projects/rocket/knowledge \
  -H 'content-type: application/json' \
  -H "x-expected-revision: 3" \
  -d @./fixtures/rocket.knowledge.json
```

`fixtures/rocket.knowledge.json` 最小形态：

```json
{
  "stages": [
    {"key":"upstream","label":"上游","order":1,
     "categories":[{"id":"cat-up","title":"推进","order":0,
                    "itemIds":["item-1"],"experience":{"kind":"panorama"}}]},
    {"key":"midstream","label":"中游","order":2,"categories":[]},
    {"key":"downstream","label":"下游","order":3,"categories":[]}
  ],
  "items":{"item-1":{"id":"item-1","categoryId":"cat-up","title":"发动机","description":"","order":0}}
}
```

### 3.4 上传 HTML scene bundle（可选）

```bash
zip -j fixtures/scene.zip fixtures/scene/index.html
curl -X POST "http://localhost:8788/api/projects/rocket/assets/html-bundle?id=asset-scene-1&expectedRevision=4" \
  -H 'content-type: application/zip' \
  --data-binary @./fixtures/scene.zip
```

### 3.5 配置产品 + 集成

```bash
curl -X PUT http://localhost:8788/api/projects/rocket/products/atlas \
  -H 'content-type: application/json' -H "x-expected-revision: 5" \
  -d @./fixtures/atlas-config.json

curl -X PUT http://localhost:8788/api/projects/rocket/products/catalog \
  -H 'content-type: application/json' -H "x-expected-revision: 6" \
  -d @./fixtures/catalog-config.json
```

### 3.6 读取完整项目核对

```bash
curl http://localhost:8788/api/projects/rocket | jq '.data.knowledge.stages | length'
# 必须 = 3
```

## 5. 原子发布（核心验收点）

```bash
curl -X POST http://localhost:8788/api/projects/rocket/releases
```

期望产物路径 `data/releases/rocket/<version>/`，目录结构：

```
release.json
atlas/
   index.html      ← 生成
   manifest.json   ← 编译自 NormalizedProject
   assets/...
catalog/
   index.html
   manifest.json
   assets/...
```

发布失败回滚验证（手动把 `release.json` 改成非法 URL 重发）：

```bash
# 把 atlas/manifest.json 里的 panorama.url 改成 /api/...
# 再次 POST /api/projects/rocket/releases
# 期望 400 VALIDATION_FAILED；data/releases/rocket/<version>/ 不存在
```

## 6. 静态自包含验证（关键不变性）

关掉 Express 后端（Ctrl-C 步骤 2 的 8788 进程），用静态服务器起产物：

```bash
cd data/releases/rocket/<version>
python -m http.server 8001
# 或：npx serve -l 8001 .
```

浏览器：

- `http://localhost:8001/atlas/index.html` — Atlas 运行时加载
- `http://localhost:8001/catalog/index.html` — Catalog 运行时加载

**两个页面都必须仍然能跑**：runtime 只依赖 `./assets/` 相对路径，没有 `/api/` 调用。如果出现 `Mixed Content` 或 `404`，产物违反自包含，回到步骤 5 查 StaticValidator 报告。

## 7. 浏览器 E2E（人工 smoke）

启动 admin：

```bash
npm run dev:admin        # vite，端口 5173
```

依次打开：

- `http://localhost:5173/projects/rocket/atlas-editor`
  - 左栏 3 stage → category 树
  - 中栏画布拖动 hotspot / marker
  - 右栏 Inspector 修改坐标，实时预览同步
- `http://localhost:5173/projects/rocket/catalog-editor`
  - 左栏三段列表
  - 中栏画布 focusRect 拖框
  - 右栏 Inspector 同步

UI 没有 jsdom 单测覆盖（smoke test 只验 importable），所以**画布拖拽 + 实时预览同步**必须肉眼复核。

## 8. 视觉回归（与 Phase 0 baseline 对照）

打开 `tests/fixtures/guide_surface_validation_001.{atlas,catalog}.json`（Phase 0 冻结的预期快照），对照产物的运行时表现：

- Atlas：默认 viewport 与 baseline 描述一致？激活 category 的 hotspot 位置正确？callout 文案一致？
- Catalog：3 段顺序正确？激活 category 的 focusRect 与基线 `[0,1]` 坐标一致？viewport 动画时长 = 配置？

任何不一致都视为回归。
