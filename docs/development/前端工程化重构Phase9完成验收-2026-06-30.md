## 3. 关键设计决策

### 3.1 Path alias 与全局 JSX

- `@shared/*` / `@domain/*` / `@products/*` 在 `tsconfig.json` 与 `vite.config.ts` 双侧声明。
- `global.d.ts` 在 React 19 下显式 re-export JSX 全局命名空间，去掉每个文件的 `import type { JSX }`。

### 3.2 乐观本地草稿 + Save 提交

- 编辑器内部用 `useState<GuideProject>` 持有草稿，UI 操作直接改草稿并标记 `pendingXxx = true`。
- Save 时只提交"被改过"的子段（panorama / atlas config / catalog config），`x-expected-revision` 头保证乐观锁。
- 409 → "保存冲突"提示 + 自动不重置 dirty；其他 → 错误状态码透传。

### 3.3 tuple 类型处理（IndustryChain.stages）

`stages: [上游, 中游, 下游]` 是 3 元组。`.map()` 返回数组，TS 会抱怨类型漂移。`AtlasEditor` 内提供 `mapStages(stages, fn)`：

```ts
const out: IndustryStage[] = [stages[0], stages[1], stages[2]].map(fn)
return out as unknown as IndustryChain['stages']
```

既保留 tuple 形状，又能让 `.map()` 像数组一样工作。

### 3.4 字段组件的事件签名统一

`TextField` / `NumberField` / `SelectField` 的 `onChange` 都采用**值语义**而不是事件语义：

| 组件 | value 类型 | onChange 参数 |
| --- | --- | --- |
| `TextField` | `string` | `(next: string) => void` |
| `NumberField` | `number` | `(next: number) => void` |
| `SelectField` | `string` | `(next: string) => void` |

调用方不需要 `e.target.value` 取数，也不需要 `parseFloat`。

### 3.5 dnd-kit 的 modifier 用法

`restrictToParentElement` 是单个 `Modifier`，必须放进数组：`modifiers={[restrictToParentElement]}`。否则类型不匹配。

### 3.6 全局快捷键 + 编辑器快捷键

`useGlobalShortcuts` 注册在两个 editor 内，分别声明各自需要的快捷键：

| Atlas | Catalog |
| --- | --- |
| `⌘/Ctrl+S` 保存 | `⌘/Ctrl+S` 保存 |
| `V` 选工具 | `Esc` 清选 |
| `M` marker 工具 | — |
| `C` callout 工具 | — |
| `Esc` 清选 | — |

hook 自动跳过 `<input>` / `<textarea>` / `[contenteditable]`。

## 5. 后续可选优化

非阻塞，按优先级分：

1. **代码分块**：当前 bundle 779 KB，gzip 224 KB。可引入 lazy import + 路由级分块，把 admin 减半。
2. **MSW 替换后端 stub**：当前 `useProject` 直接打 `/api`，开发体验依赖真实后端。引入 MSW 可离线编辑。
3. **大项目的画布性能**：超 200 个 hotspot 时需要 viewport culling。当前 `AtlasCanvas` 直接渲染全部。
4. **i18n**：目前文案中文硬编码。若需要双语，复用方案内 §10 的 i18n 切面（依赖 `_i18n.t(key)`）。
5. **Storybook**：13 个通用组件 + 9 个编辑器组件值得独立索引。
