## 1. 核心概念与命名

| 概念 | 命名 | 含义 |
|------|------|------|
| 导览 | **Guide** | 顶层业务实体。一个导览包含若干节点（页面）和边（跳转关系），描述一个交互式探索流程 |
| 节点 | **Node** | 导览中的一个页面。包含标题、内容块、热点列表 |
| 边 | **Edge** | 节点间的跳转关系。从一个节点通过点击热点到达另一个节点 |
| 热点 | **Hotspot** | 节点上的可点击区域。点击后沿关联的边跳转到目标节点 |
| 生成 | **Generate** | AI 编译过程。将导览的结构数据转换为视觉产物（节点图片、过渡视频） |
| 生成记录 | **GenerateRecord** | 一次生成过程的状态跟踪记录 |
| 运行清单 | **Manifest** | 生成产物的索引文件。前端播放器仅依赖 manifest + assets |

**业务流程**：

```
导入/编辑导览（节点 + 边 + 热点）
        │
        ▼
    触发"生成"
        │
        ├─ Vision 模型 → 为每个节点生成图片 prompt
        ├─ Image 模型 → 为每个节点生成页面图片
        ├─ Video 模型 → 为每条边生成过渡视频（异步）
        └─ 输出 manifest.json + assets/
                │
                ▼
        前端播放器加载 manifest，用户交互式探索
```

## 3. API 设计

### 3.1 端点清单

**routes/health.ts**：

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/health` | `{ status: 'ok', timestamp }` |

**routes/guides.ts**：

| 方法 | 路径 | 业务方法 | 说明 |
|------|------|---------|------|
| `GET` | `/guides` | `guideService.listGuides()` | 导览列表（摘要） |
| `GET` | `/guides/:id` | `guideService.getGuide(id)` | 导览详情 |
| `POST` | `/guides/import` | `guideService.importGuide(body)` | 导入导览 |
| `PUT` | `/guides/:id` | `guideService.updateGuide(id, body)` | 更新导览元数据 |
| `DELETE` | `/guides/:id` | `guideService.deleteGuide(id)` | 删除导览 |
| `PUT` | `/guides/:gid/nodes/:nid` | `guideService.updateNode(gid, nid, body)` | 更新节点 |
| `PUT` | `/guides/:gid/nodes/:nid/hotspots` | `guideService.updateHotspots(gid, nid, body)` | 更新热点 |
| `PUT` | `/guides/:gid/edges/:eid` | `guideService.updateEdge(gid, eid, body)` | 更新边 |
| `GET` | `/guides/:id/manifest` | `guideService.getManifest(id)` | 获取运行清单 |

**routes/generates.ts**：

| 方法 | 路径 | 业务方法 | 说明 |
|------|------|---------|------|
| `POST` | `/guides/:id/generate` | `generateService.startGenerate(id)` | 触发生成 |
| `GET` | `/generates/:generateId` | `generateService.getRecord(generateId)` | 查询生成状态 |
| `POST` | `/generates/:generateId/cancel` | `generateService.cancelGenerate(generateId)` | 取消生成 |
| `GET` | `/generates/:generateId/logs` | `generateService.getLogs(generateId)` | 生成日志 |
| `POST` | `/guides/:gid/nodes/:nid/regenerate` | `generateService.regenerateNode(gid, nid)` | 重跑单个节点 |
| `POST` | `/guides/:gid/edges/:eid/regenerate` | `generateService.regenerateEdge(gid, eid)` | 重跑单条边 |

### 3.2 统一响应格式

```typescript
// 成功
{ "data": <payload> }

// 失败
{ "error": "Human-readable message", "code": "MACHINE_CODE" }

// 错误码
VALIDATION_ERROR     // 输入校验失败
NOT_FOUND            // 资源不存在
GENERATE_FAILED      // 生成失败
AI_SERVICE_ERROR     // AI 服务调用失败
CONFIG_ERROR         // 配置缺失
INTERNAL_ERROR       // 未预期错误
```

### 3.3 中间件链

```
请求 → CORS → JSON Parser → 路由匹配 → 全局错误处理
                                        ├─ 已知错误 → { error, code }
                                        └─ 未知错误 → { error: "Internal", code: "INTERNAL_ERROR" }
```

export interface FileRepository {
  writeJson(filePath: string, data: unknown): void
  readJson<T>(filePath: string): T | null

  ensureDir(dir: string): void

## 5. 业务服务层

### 5.1 guide-service.ts

```typescript
export class GuideService {
  constructor(private repo: Repository) {}

  // 导览 CRUD
  listGuides(): GuideListItem[]
  getGuide(id: string): Guide
  importGuide(data: unknown): Guide
  updateGuide(id: string, updates: Partial<Guide>): Guide
  deleteGuide(id: string): void

  // 节点 CRUD
  updateNode(guideId: string, nodeId: string, updates: Partial<Node>): Node
  updateHotspots(guideId: string, nodeId: string, hotspots: HotspotInput[]): Node

  // 边 CRUD
  updateEdge(guideId: string, edgeId: string, updates: Partial<Edge>): Edge

  // 运行清单
  getManifest(guideId: string): Manifest | null
}
```

**输入校验**：

| 方法 | 校验规则 |
|------|---------|
| `importGuide` | `validateGuide(data)` → errors 非空则抛 400 |
| `updateGuide` | 禁止覆盖 `id`, `nodes`, `edges` |
| `updateNode` | 禁止覆盖 `id` |
| `updateHotspots` | 每项 `normalizedX/Y ∈ [0,1]`，`edgeId/targetNodeId` 引用存在 |
| `updateEdge` | 禁止覆盖 `id`, `fromNodeId`, `toNodeId` |

### 5.2 generate-service.ts

```typescript
export class GenerateService {
  constructor(
    private repo: Repository,
    private vision: typeof import('../ai/vision.js'),
    private image: typeof import('../ai/image.js'),
    private video: typeof import('../ai/video.js'),
    private media: typeof import('../ai/media.js'),
  ) {}

  startGenerate(guideId: string): GenerateRecord
  cancelGenerate(generateId: string): void
  getRecord(generateId: string): GenerateRecord
  getLogs(generateId: string): string[]
  regenerateNode(guideId: string, nodeId: string): void
  regenerateEdge(guideId: string, edgeId: string): void

  private runGenerate(generateId: string): Promise<void>
  private generateNodes(generateId: string, guide: Guide, record: GenerateRecord): Promise<void>
  private generateHotspots(generateId: string, guide: Guide, record: GenerateRecord): void
  private generateEdges(generateId: string, guide: Guide, record: GenerateRecord): Promise<void>
  private publishFromGenerate(generateId: string, guide: Guide): void
  private buildManifest(guide: Guide, generateId: string): Manifest
}
```

**六阶段管线**：

```
startGenerate(guideId)
  │
  ├─ 1. validate       校验导览结构
  ├─ 2. prepare        创建生成目录 + 写入快照
  ├─ 3. gen_nodes      对每个节点：
  │     ├─ ai/vision.planNodeImage()    → planner.json
  │     └─ ai/image.generateNodeImage() → image.png
  ├─ 4. gen_hotspots   对每个有热点的节点：
  │     └─ hotspots.final.json
  ├─ 5. gen_edges      对每条边：
  │     ├─ buildTransitionPrompt()      → transition.json
  │     ├─ ai/media.exposeNodeImage()   → HTTP URLs
  │     └─ ai/video.generateTransitionVideo() → transition.mp4
  └─ 6. publish        复制产物 → manifest.json
```

**失败处理**：

| 场景 | 结果 |
|------|------|
| 校验失败 | 状态 = `failed`，写 validation-report.json |
| 单节点失败 | node-record 含 errorMessage，继续下一个 |
| 单边失败 | edge-record 含 errorMessage，继续下一个 |
| 全部失败 | 状态 = `failed` |
| 部分失败 | 状态 = `partial_failed` |
| 全部成功 | 状态 = `success` |

## 8. 数据流

### 8.1 生成流

```
POST /api/guides/:id/generate
  │ routes/generates.ts → generateService.startGenerate(id)
  │ 返回 GenerateRecord { generateId, status: 'running' }
  │
  ▼ generate-service.ts: runGenerate() 异步执行
  │
  ├─ validate   → validators.validateGuide()
  ├─ prepare    → repo.writeJson(generate.json, snapshot)
  ├─ gen_nodes  → for each node:
  │    ├─ ai/vision.planNodeImage()     → repo.writeFile(planner.json)
  │    └─ ai/image.generateNodeImage()  → repo.writeFile(image.png)
  ├─ gen_hotspots → repo.writeFile(hotspots.final.json)
  ├─ gen_edges  → for each edge:
  │    ├─ buildTransitionPrompt()       → repo.writeFile(transition.json)
  │    ├─ ai/media.exposeNodeImage()    → HTTP URLs
  │    └─ ai/video.generateTransitionVideo() → repo.writeFile(transition.mp4)
  └─ publish    → repo.copyFile() × N → repo.writeJson(manifest.json)

客户端轮询 GET /api/generates/:generateId → 获取实时状态
```

### 8.2 导入流

```
POST /api/guides/import
  │ routes/guides.ts → guideService.importGuide(body)
  │
  ├─ validators.validateGuide(data) → errors? → throw 400
  ├─ 补充 metadata
  └─ repo.saveGuide(guide) → data/guides/{id}/current/guide.json
```
