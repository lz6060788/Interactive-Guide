# 双产品 HTML 标题与资料来源文案设计

## 目标

- Atlas 和 Catalog 独立产物的 HTML `<title>` 均使用当前项目的 `project.title`。
- Atlas 和 Catalog 共用说明弹窗中的“资料来源”默认文案替换为新的通用表述，删除证券公司名称。

## HTML 标题

- `buildProductShell` 接收项目标题，由静态产品构建器传入 `project.title`。
- Atlas 与 Catalog 使用完全相同的项目标题，不追加产品名称或其他后缀。
- 标题在构建阶段写入 `index.html`，不依赖 manifest 加载或运行时 JavaScript。
- 写入前转义 HTML 特殊字符，避免项目标题破坏 `<title>`。

## 资料来源

共用默认文案固定为：

> 本产业链图谱基于公开研报，以及行业公开资料、网络公开信息整理。节点分类、层级关系、说明文案及部分可视化形式由 AI 辅助归纳、生成和编辑，可能存在遗漏、简化或不准确之处。

- 更新平台层 `HOST_INFO_SHEET_DEFAULT_SECTIONS`，两份产品运行时同步生效。
- 同步更新旧管理组件中的重复默认值，避免遗留入口重新带出旧文案。
- 若未来项目实例提供显式自定义说明，仍优先使用项目配置；本次不修改数据结构。

## 验收

- 构建 Atlas 与 Catalog 时，两份 `index.html` 的 `<title>` 均等于项目标题。
- 含 `&`、`<`、`>` 的项目标题可安全写入 HTML。
- 共用说明弹窗和旧管理组件的默认“资料来源”均为新文案。
- 两份独立产物继续通过 ES5 语法与静态产物校验。

## 实施结果（2026-07-15）

- 静态产品构建器已将 `project.title` 传入共享 HTML Shell，Atlas 与 Catalog 不再使用产品名硬编码标题。
- 平台共用说明弹窗和旧管理组件的“资料来源”默认文案均已替换。
- 按本轮要求未新增或运行测试。
