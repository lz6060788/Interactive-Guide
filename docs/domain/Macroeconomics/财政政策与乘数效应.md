# 财政政策与乘数效应

财政政策通过政府收支变动直接影响总需求，其核心机制在于乘数效应：一笔初始财政注入会在经济中循环流转，产生数倍于原始支出的总需求扩张，如同**财政支出的放大镜**将政府行为的效果成倍放大。

政府支出乘数的大小取决于边际消费倾向。若民众每增加一元收入便消费零点八元，则支出乘数为五。这意味着一百亿元的基建投资最终可带来五百亿元的总需求增长。税收乘数同样存在，但绝对值略小于支出乘数，因为减税首先增加的是可支配收入，只有部分被用于消费。

平衡预算乘数是一个特殊情形：政府等量增加支出与税收时，净预算为零，但总需求仍会增加。原因在于支出增加直接计入总需求，而税收增加仅部分减少可支配收入，二者并非一对一抵消。

现代财政体系还内置了自动稳定器。经济衰退时，失业救济支出自动增加、税收自动减少，无需立法即可缓冲下行；经济过热时则自动反向运作。然而，财政政策也面临挤出效应的风险：政府大规模借债可能推高利率，挤占私人投资空间，削弱政策的净效果。
