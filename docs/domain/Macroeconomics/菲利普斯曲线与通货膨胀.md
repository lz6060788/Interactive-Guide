# 菲利普斯曲线与通货膨胀

菲利普斯曲线描述了失业率与通货膨胀率之间的负相关关系，是总供给分析中最富政策争议的命题之一。其原始形式基于英国历史数据，发现工资增长率与失业率呈反向变动：失业低则工资涨得快，失业高则工资增长缓慢。

经济学家将工资通胀推广至一般物价水平，形成了失业与通胀之间的**拉锯绳**。在短期内，政府似乎可以通过扩张性政策降低失业率，代价是接受较高的通货膨胀率；反之，紧缩政策抑制通胀，却会导致失业上升。这种替代关系为需求管理政策提供了操作空间。

然而，米尔顿·弗里德曼与埃德蒙·费尔普斯指出，这种替代关系仅在通货膨胀未被预期时成立。一旦工人与企业形成通胀预期，他们会将预期纳入工资谈判与定价决策，菲利普斯曲线将向上移动。长期中，经济会回到自然失业率水平，此时失业与通胀不再存在替代关系，扩张政策只会导致通胀加速而无助于降低失业。

这一发现深刻影响了后来的货币政策框架，使央行将稳定通胀预期视为首要任务，而非试图在长期中利用菲利普斯曲线进行权衡。
