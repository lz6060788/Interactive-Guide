# 名义GDP与实际GDP

名义GDP以当期市场价格计算总产出，实际GDP则以固定基期价格计算总产出。二者的差额完全来自价格水平的变动。当通货膨胀存在时，名义GDP的增长会夸大经济的真实扩张，如同一杯掺了水的酒，容量虽增，纯度却降。

区分二者的核心工具是GDP平减指数，计算公式为名义GDP除以实际GDP再乘以一百。该指数综合反映国内生产的全部商品与服务的价格变动，是度量通胀水平的重要指标之一。当平减指数大于一百时，表明整体价格水平相对于基期上涨。

以固定价格计算的实际GDP消除了价格杂质的干扰，使不同年份的产出具有可比性。经济学家在判断经济是否真正增长时，几乎总是关注实际GDP的变动。若名义GDP上升百分之五而实际GDP仅上升百分之二，则意味着经济实际增量有限，其余三个百分点只是价格上涨的幻象。

理解名义与实际的区别，是正确解读宏观经济数据的基本功。无论是评估政策效果还是进行跨国比较，都必须先问一句：这个数字是名义的还是实际的？
