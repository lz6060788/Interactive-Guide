# 宏观经济政策工具

宏观经济的稳定运行不能仅依赖市场自发调节。当经济面临衰退或过热时，政府需要运用系统性政策工具进行干预，以实现充分就业、物价稳定、经济增长与国际收支平衡四大目标。

政策工具箱中最重要的两件器械分别作用于货币层面和财政层面。央行通过**[[货币政策工具与传导机制|货币流量的水龙头]]**控制货币供给的松紧：拧松水龙头，市场流动性充裕，利率下降，刺激投资与消费；拧紧水龙头，则抑制通胀压力。公开市场操作、准备金率与再贴现率构成龙头的三个旋钮。

另一方面，政府通过**[[财政政策与乘数效应|财政支出的放大镜]]**将公共投入的初始效应成倍放大。一笔基建支出不仅直接创造就业，还会通过连锁反应带动上下游产业，形成数倍于原始支出的总需求扩张。税收减免同样能通过乘数机制间接刺激经济。

货币政策与财政政策并非孤立运作。理想状态下，二者应协调配合：在经济衰退期双管齐下，在通胀期双双收紧。政策搭配的艺术在于把握力度与时机，避免因政策冲突而相互抵消，或因过度刺激而埋下新的失衡隐患。
