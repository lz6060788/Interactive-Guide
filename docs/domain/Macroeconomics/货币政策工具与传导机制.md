# 货币政策工具与传导机制

中央银行通过调节货币供给与利率水平来实现物价稳定与经济增长目标。其政策操作如同控制**货币流量的水龙头**，央行通过三大传统工具调节水流大小。

第一，公开市场操作。央行在金融市场上买卖政府债券，买入债券向市场注入基础货币，卖出债券则回笼资金。这是日常最频繁、最精准的调控手段。

第二，法定存款准备金率。上调准备金率会冻结商业银行可贷资金，收缩货币乘数；下调则释放流动性。这一工具力度较大，通常作为辅助手段。

第三，再贴现率。央行调整向商业银行提供贷款的利率，影响商业银行的融资成本，进而传导至市场利率。

货币政策的效果依赖传导机制。利率渠道是最核心的路径：央行政策利率影响市场利率，进而改变投资与消费成本。信贷渠道则强调银行放贷意愿的独立作用，尤其在金融危机时期，即使利率降低，银行惜贷也会阻断传导。非常规时期，央行还可能启动量化宽松，直接购买长期资产以压低长端利率。
