# 宏观经济学总览

宏观经济学以整个国民经济为研究对象，关注经济总量的决定、波动与调控。与微观经济学聚焦个体决策不同，宏观经济学回答的是"经济总体有多大""为什么有人失业""物价为何上涨"等全局性问题。

现代宏观经济学围绕三大核心维度展开。首先是度量维度：我们需要一本**[[GDP与国民经济核算|经济核算的账本]]**来系统记录经济活动的总量，为后续分析提供数据基础。没有可靠的度量，宏观经济学就成了空中楼阁。

其次是均衡维度。宏观经济的运行依赖于多重市场的交互作用，如同一个**[[总需求与总供给分析|供需交汇的十字路口]]**，供给方与需求方在此处交汇，共同决定总产出水平和一般价格水平。短期经济波动往往源于这个路口的失衡。

最后是调控维度。当市场自发调节出现失灵，导致失业或通胀持续恶化时，政府必须打开**[[宏观经济政策工具|调控经济的工具箱]]**，运用货币政策与财政政策进行干预，引导经济回到充分就业与物价稳定的轨道。

这三大维度相互支撑、层层递进：先度量，再分析均衡机制，最后在必要时实施调控，共同构成宏观经济学的完整分析框架。
