# GDP核算的三种方法

国民经济核算体系为GDP提供了三种相互独立又内在一致的核算路径，如同从正面、侧面与背面观察同一座雕塑，每种视角揭示经济运行的不同侧面。

生产法从价值创造的角度入手，计算公式为：总产出减去中间投入等于增加值，各产业增加值之和即为GDP。这种方法清晰展示了农业、工业与服务业各自对经济的贡献份额，适用于分析产业结构变迁。

收入法从生产要素报酬的角度核算，将劳动者报酬、生产税净额、固定资产折旧与营业盈余加总。GDP等于这四项收入之和。收入法揭示了经济蛋糕如何在劳动、资本与政府之间初次分配，是研究收入分配格局的重要数据来源。

支出法从最终使用的角度衡量，公式为GDP等于消费加投资加政府购买再加净出口。这种方法将经济活动划分为四大需求部门，直观反映经济增长是由内需还是外需驱动。

理论上，三种方法核算的GDP应完全相等，这种三面映照的一致性本身就是国民经济核算体系严谨性的体现。实践中由于数据来源与统计误差存在微小差异，统计部门会通过调整项予以平衡。
