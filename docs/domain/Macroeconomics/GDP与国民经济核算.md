# GDP与国民经济核算

国内生产总值（GDP）是衡量一国经济规模最核心的指标，它统计特定时期内一国领土范围内生产的所有最终商品与服务的市场价值总和。作为宏观经济分析的基石，GDP为判断经济周期、制定政策提供了量化依据。

GDP核算并非简单的数字加总，而是一套严谨的方法论体系。同一笔经济交易可以通过**[[GDP核算的三种方法|核算GDP的三面镜]]**来观察：生产法从产出角度核算，收入法从要素报酬角度核算，支出法从最终使用角度核算。三面镜子映照同一对象，理论上应得出完全一致的结果，这种恒等关系构成了国民经济核算的内在一致性检验。

然而，GDP并非万能。名义GDP容易受到价格水平变动的干扰，如同水中月、镜中花，无法真实反映实物产出的变化。因此，经济学家需要借助**[[名义GDP与实际GDP|滤除价格杂质的筛网]]**，将价格因素剔除，计算出实际GDP，从而准确比较不同时期的经济真实增长。

尽管GDP存在忽略分配公平、不计环境成本等局限，但它至今仍是宏观经济决策不可或缺的度量工具。理解GDP的核算逻辑与局限，是进入宏观经济学大门的第一级台阶。
