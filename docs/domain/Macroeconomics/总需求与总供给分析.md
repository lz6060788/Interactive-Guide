# 总需求与总供给分析

总需求与总供给（AD-AS）模型是宏观经济学分析短期波动与长期增长的核心框架。总需求反映经济中各部门在每一价格水平下愿意购买的总量，总供给则反映企业在每一价格水平下愿意生产的总量。二者的交汇决定均衡产出与均衡价格水平。

在总需求侧，经济萧条时期往往出现有效需求不足，市场如同电量耗尽的设备，无法自行重启。此时需要**[[凯恩斯总需求理论|为经济充电的电池]]**来激活消费、投资与政府支出，通过扩张总需求将经济拉回潜在产出水平。凯恩斯主义革命性地将总需求置于宏观经济分析的中心位置。

在总供给侧，经济并非总能平稳运行。失业率与通货膨胀率之间存在微妙的替代关系，如同一根**[[菲利普斯曲线与通货膨胀|失业与通胀的拉锯绳]]**，政策制定者拉动一端，另一端就会反向移动。短期中降低失业可能以通胀为代价，长期中这种替代关系则会因预期调整而消失。

AD-AS框架将需求管理与供给约束统一在一个坐标系中，既解释了经济为何偏离均衡，也为宏观政策提供了施策的坐标。掌握这一模型，是理解后续政策分析的必要前提。
