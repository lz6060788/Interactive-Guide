# 凯恩斯总需求理论

约翰·梅纳德·凯恩斯在大萧条背景下创立了以总需求为核心的宏观经济学。其核心论断是：市场经济并非总能自发实现充分就业均衡，有效需求不足可能导致经济长期停滞于低产出水平。

凯恩斯认为有效需求不足源于三大心理规律。第一是边际消费倾向递减，收入增加时消费占比下降；第二是资本边际效率递减，投资者对未来收益预期转弱；第三是流动性偏好，人们倾向于持有现金而非投资。三股力量共同导致私人部门的消费与投资不足以吸纳全部产出。

凯恩斯交叉图直观展示了这一机制。四十五度线代表总供给等于总需求，总支出曲线则因三大心理规律而低于充分就业水平。两条线的交点决定了低于潜能的均衡产出，此时非自愿失业普遍存在。

既然私人部门无法自行修复，政府就必须充当**为经济充电的电池**，通过增加公共支出或减税来填补需求缺口。财政扩张不仅直接创造需求，还通过乘数效应带动第二轮、第三轮消费。这一理论彻底改变了人们对政府经济职能的认知，奠定了现代宏观政策的需求管理范式。
